# Islet – Dynamic Island for your Mac
1. Create a GitHub repo named Islet, copy all these files in (including the hidden .github folder).
2. On github.com open Actions > Build Islet > Run workflow.
3. When it shows a green tick, open the run and download the Islet-dmg artifact (unzip it to get Islet.dmg).
4. Drag Islet to Applications, right-click > Open the first time.
